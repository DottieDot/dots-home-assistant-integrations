# HA HomeKit Room Sync

Keeps Home Assistant Areas synchronized with Apple HomeKit rooms by managing **one HomeKit Bridge per Area**.

## One-time setup

1. Install via HACS and restart Home Assistant.
2. Add the integration and select your Areas.
3. Pair each created HomeKit Bridge in the Apple Home app into the matching room.

After that, adding, removing, or moving devices between Areas in Home Assistant updates HomeKit automatically.
